# Phase 4 — Customer Catalog

Implemented:
- Published product customer catalog shortcode `[avanik_product_catalog]`
- Destination and product-type filtering
- Product media attachment foundation
- Product-type metadata schema for tours, hotels, flights and packages
- Wiring into the Avanik theme bootstrap

The catalog intentionally reads only `published` products. Supplier and moderation workflows remain separate.

Next: customer product detail pages, booking CTA, availability/calendar, image gallery UI, and type-specific editor fields.
