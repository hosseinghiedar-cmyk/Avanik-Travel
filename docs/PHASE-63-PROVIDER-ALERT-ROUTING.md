# Phase 63 — Provider Health Alert Routing

Phase 63 connects the Phase 62 escalation decision to Avanik's existing notification queue.

## Routing policy
- Only alerts marked `escalated` are routed.
- The route is `provider_health_escalation`.
- Recipients are administrator users.
- Delivery channel is `internal` only; no customer email/SMS is generated by this phase.
- A separate escalation route log and the existing cooldown prevent duplicate routing.

## Integration
The evaluator now passes alerts through `avanik_notification_provider_health_alert_escalate` and then `avanik_notification_provider_health_alert_route`.

The router supplies administrator recipients through the existing `avanik_notification_recipients` filter and delegates queue persistence to `NotificationCenter::enqueue()`.

Phase 63 also registers the Phase 62 escalation class in the main theme bootstrap, completing the previously missing bootstrap registration.

No credentials or external request/response bodies are included in routed payloads.
